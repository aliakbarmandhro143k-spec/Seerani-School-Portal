SEERANI DIGITAL PORTAL - 11 NEW FEATURES
=========================================

Is folder mein kya hai
- features.html  : sab 11 features ka main page (hub)
- 11 pages       : papers, student-achievements, school-achievements, teachers,
                   notices, library, tests, steam, calendar, gallery, english
- css/portal.css : design
- js/portal.js   : code (isay chherne ki zaroorat nahi)
- js/data.js     : AAPKI SAARI MALOOMAT YAHAN HAI (teachers, notices, papers...)

Maloomat badalne ka tareeqa
1. GitHub par repository kholein -> js -> data.js -> pencil (Edit) icon.
2. Jis section mein add karna ho, ek line copy karke paste karein aur text badal dein.
   Har line ke aakhir mein koma (,) zaroor ho, siwaye aakhri line ke.
3. "Commit changes" dabayein. 1-2 minute baad site update ho jayegi.
4. "(SAMPLE)" wali entries namoona hain - unhe asal data se badal dein.

PDF / photos upload karna
- Past papers:  papers/class6/ ... papers/class10/   (data.js mein file path likhein)
- Library:      library/books/  library/notes/  library/pdfs/
- Gallery:      images/gallery/
- Teachers:     images/teachers/       Students: images/students/
- STEAM:        images/steam/
GitHub mein "Add file -> Upload files" se folder samet upload ho jata hai.
Photos 1 MB se chhoti rakhein (site tez chalegi).
